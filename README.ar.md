# LLM Output Clarity: مهارة للوكلاء مستوحاة من أفكار Karpathy

**افهم الخلاصة. راجع الأدلة. حدّد الخطوة التالية.**

[English](./README.md) | [简体中文](./README.zh-CN.md) | [日本語](./README.ja.md) | [Español](./README.es.md) | [العربية](./README.ar.md)

[التثبيت](./docs/installation.md) | [التصميم](./docs/design.md) | [التقييم](./evals/README.md)

تساعد هذه المهارة وكيل الذكاء الاصطناعي على تقديم المخرجات المعقدة في صورة نص واضح،
أو مخطط، أو صفحة HTML تفاعلية، أو فيديو توضيحي. الهدف ليس تقليل الكلمات بأي ثمن،
بل تسهيل الفهم مع الحفاظ على الحقائق والشروط والأدلة ودرجة اليقين.

الفكرة مستوحاة من [منشور Andrej Karpathy بتاريخ 2 أكتوبر 2026](https://x.com/karpathy/status/2105819303471976479).
كلما أنجزت الوكلاء مزيداً من العمل، احتاج الناس إلى فهم النتائج ومراجعتها.
يقترح المنشور كتابة قريبة من ASD-STE100، ومخططات وصوراً، وصفحات تفاعلية، وفيديوهات مخصصة للشرح.

هذا مشروع مستقل، ولا توجد صلة رسمية أو مصادقة من Karpathy أو ASD.
ليس أداة للتحقق من الحقائق، ولا يمنح شهادة امتثال لمعيار ASD-STE100.

## اختيار طريقة العرض

| الطريقة | متى تفيد؟ | ما الذي تتضمنه المهارة؟ |
| --- | --- | --- |
| نص واضح | الخلاصة والشرح والتوصيات | قواعد للوضوح والحفاظ على الأدلة |
| مخططات وصور | العلاقات والتفرعات والتسلسل والبنية المكانية | اختيار المخطط وتمييز الفرضيات وتقديم بديل نصي |
| HTML تفاعلي | مقارنة الحالات أو تغيير القيم أو استكشاف التفاصيل | إرشادات لصفحات سهلة الاستخدام تعمل دون اتصال |
| فيديو توضيحي | عندما تساعد الحركة والتعليق الصوتي على الفهم | خطوات للنص ولوحة المشاهد والتصيير والتحقق |

السؤال البسيط لا يحتاج إلى مخطط. يتطلب إنشاء HTML أو فيديو طلباً صريحاً أو موافقة.
المهارة لا تتضمن متصفحاً أو محرّك فيديو أو نموذج صوت، ولا تثبّت أدوات أو خدمات مدفوعة تلقائياً.

## مثال افتراضي

المعطيات: أعادت ثلاثة طلبات من أصل عشرين الرمز HTTP 429.
قد تفرض البوابة أو الخدمة اللاحقة حدّاً على الطلبات، ورؤوس الاستجابة غير متاحة.

**صياغة مضللة:** «حصة البوابة غير كافية. ارفع عدد الطلبات المتزامنة».

**صياغة أوضح:** «لا ترفع عدد الطلبات المتزامنة الآن. أعادت ثلاثة طلبات الرمز 429،
لكن الخدمة التي فرضت الحدّ غير معروفة. افحص رؤوس الاستجابة والسجلات المرتبطة
بالطلبات الفاشلة قبل اختيار تغيير للحصة أو التزامن».

هذا مثال مكتوب للسلوك المطلوب، وليس نتيجة تجربة على نموذج.
تحافظ القواعد أيضاً على نسبة الأقوال إلى مصادرها، وتراجع الاستنتاج عند ظهور أدلة جديدة،
وتحترم الطلبات ذات الصيغة الدقيقة مثل JSON فقط. تبدأ مراجعة الشيفرة بالملاحظات
الأكثر خطورة، ولا تفرض المهارة قالباً واحداً على جميع المهام.

## التثبيت

ثبّت المهارة مباشرة من مستودع GitHub:

```sh
npx skills add stoneboy100200/llm-output-clarity --skill llm-output-clarity --global --copy
```

تستخدم Claude Code وCodex وCursor وGemini CLI وOpenCode وGitHub Copilot وغيرها
المجلد القياسي نفسه بصيغة Agent Skills. تكتشف Skills CLI الأدوات وتطلب اختيارها عند الحاجة.
راجع الأهداف في ملخص التثبيت. للتثبيت غير التفاعلي حدّد `--agent` صراحةً،
ولا تستخدم `--all` بدلاً من اختيار الأدوات المطلوبة.
تحتاج أداة التثبيت الخارجية Skills CLI إلى Node.js واتصال بالشبكة وإذن للكتابة.
لا يحتاج استخدام المهارة نفسها إلى تشغيل `npm install`.
يوضح [دليل التثبيت](./docs/installation.md) النسخ اليدوي دون اتصال وطريقة تعطيل
بيانات القياس الخاصة بالمثبّت. المهارة نفسها لا تجمع بيانات قياس.

لتحديد أدوات بعينها، أضف معرّفاً واحداً أو أكثر. مثال:

```sh
npx skills add stoneboy100200/llm-output-clarity --skill llm-output-clarity --global --copy --agent claude-code codex
```

يتضمن دليل التثبيت معرّفات أخرى ومسارات النسخ اليدوي.
دعم المثبّت للبيئة لا يعني أن سلوك هذه المهارة اختُبر فيها.

المصدر هو [stoneboy100200/llm-output-clarity](https://github.com/stoneboy100200/llm-output-clarity).
لتثبيت نسخة محلية راجعتها، استبدل معرّف المستودع بـ `.` وشغّل الأمر من مجلدها الرئيسي.
لا ينشر هذا المشروع حزمة على npm.

## الاستخدام

بعد التثبيت، يمكنك طلب المهارة باسمها دون الاعتماد على بادئة أمر خاصة بالمنصة:

```text
استخدم llm-output-clarity لتحليل هذا الخطأ بالعربية، وافصل المشاهدات عن الفرضيات.
استخدم llm-output-clarity لرسم مسار الطلب وتحديد العلاقات غير المؤكدة.
استخدم llm-output-clarity لإنشاء صفحة HTML دون اتصال تقارن الحالة السابقة واللاحقة.
استخدم llm-output-clarity لإعداد لوحة مشاهد لفيديو توضيحي. لا تثبّت برامج الآن.
```

تختلف الاختصارات المباشرة: تستخدم Claude Code الأمر `/llm-output-clarity`،
وتستخدم Codex الأمر `$llm-output-clarity`، وتستخدم Copilot الأمر `/llm-output-clarity`.
راجع قائمة المهارات في الأدوات الأخرى. يجب أن تحمّل البيئة المهارة؛ واجهة نموذج API
العادية لا تكتشف ملفات جهازك تلقائياً.
قد تختارها البيئة تلقائياً بحسب صلة المهمة، لكن ذلك غير مضمون في كل طلب.

تطبّق المهارة افتراضياً على الطلب الحالي. يمكنك طلب استخدامها لبقية الجلسة.
عبارة «Stop clarity mode» تطلب من الوكيل عدم إعادة تفعيلها في المحادثة نفسها
حتى تطلبها مجدداً. تتبع المحادثة الجديدة قواعد اكتشاف البيئة؛ لا تُحفظ حالة تشغيل دائمة.
قد يضعف الالتزام بعد ضغط سياق المحادثة. هذه تعليمات وليست آلية فرض برمجية.
التثبيت لا يغيّر التعليمات الدائمة ولا المهارات الأخرى.

## التحقق والتحديث والإزالة

```sh
npx skills list --global
```

افحص أيضاً قائمة المهارات أو الإعدادات في الأداة التي تستخدمها، وأعد التحميل أو
ابدأ محادثة جديدة عند الحاجة. سجلّ التثبيت لا يثبت أن البيئة حمّلت المهارة،
وظهورها في القائمة لا يثبت صحة السلوك. جرّب مهمة صغيرة ذات سبب غير معروف.
يتضمن دليل التثبيت خطوات تحقق خاصة بكل بيئة.

لتحديث نسخة محلية، راجع تغييرات المصدر وأعد تشغيل أمر التثبيت.
احتفظ بنسخة من تعديلاتك قبل الاستبدال. يشرح دليل التثبيت تحديث النسخ البعيدة.

لإزالة تثبيت المستخدم الذي تديره Skills CLI:

```sh
npx skills remove llm-output-clarity --global
```

قد تؤدي إزالة `--agent` من الأمر إلى حذف هذه المهارة من عدة بيئات.
أضف `--agent` لتحديد أداة واحدة، وراجع النطاق قبل التأكيد.

في حالة النسخ اليدوي، احذف مجلد هذه المهارة فقط، لا مجلد جميع المهارات.
أزل أي تفضيلات دائمة أضفتها بصورة منفصلة، ثم ابدأ محادثة جديدة.

- يحتاج HTML والفيديو إلى أدوات في البيئة المضيفة؛ تتضمن المهارة إرشادات العمل والتحقق فقط.

## لماذا لا نستخدم STE الصارم افتراضياً؟

ASD-STE100 معيار للوثائق التقنية الإنجليزية يشمل قواعد كتابة وقاموساً مضبوطاً
ومصطلحات متخصصة. قد يقلل الغموض، لكنه لا يثبت صحة الحقائق أو التشخيص، وليس
قواعد للغات الأخرى. ذكر Karpathy أنه يخفف القيود أحياناً إلى نحو «80%» لأن المعيار صارم.
هذه أفضلية أسلوبية وليست درجة امتثال قابلة للقياس.

نحافظ افتراضياً على مبادئ الوضوح مع الشروط والاستثناءات وعدم اليقين.
يمكن طلب أسلوب إنجليزي أقرب إلى STE الصارم للإجراءات، لكن ذاكرة النموذج لا تثبت
الامتثال الكامل. يحتاج الاستخدام الرسمي إلى مراجعة المعيار المناسب والقاموس
ومسرد المشروع. لا يتضمن المشروع معيار ASD أو قاموسه أو وضعاً يمنح شهادة امتثال.
