# Sources and scope

Inspired by [Andrej Karpathy's post](https://x.com/karpathy/status/2105819303471976479)
about helping humans understand model output with clear writing, diagrams,
interactive HTML, and bespoke explanatory video. No affiliation or endorsement.

Adapted with reference to [prithivrajmu/asd-ste100](https://github.com/prithivrajmu/asd-ste100)
and its credited source [danyuchn/asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill).
Their MIT notices are retained in the skill's bundled LICENSE.

[ASD-STE100](https://www.asd-ste100.org/) is ASD's standard for Simplified Technical
English. This skill does not bundle the standard or its dictionary, certify
compliance, or claim ASD endorsement. Non-English guidance adapts general clarity
principles, not the official English language specification.

The complete project contains design comparisons, test fixtures, and development
tools. An installed skill contains only this Markdown guidance and its license.
